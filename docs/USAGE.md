# leiting extension 1.2.0

Chrome / Edge Manifest V3 扩展。在网页原视频的矩形区域随机插入本地视频，不跳转页面，不替换原视频地址。

这是一个免费、开源的娱乐整活工具，可将自己有权使用的“新宿决战”等视频作为本地彩蛋。原创代码使用 [MIT 许可证](../LICENSE)；第三方视频、音频、角色形象等素材不属于该许可证的授权范围。

## 本版行为

- 默认在符合条件的视频累计播放 **1–15 秒**后随机触发，概率 **100%**，默认冷却 0 秒，同一视频自动触发一次。
- 只累计前台、约 99% 可见、正在播放且未拖动进度的视频时间；本地播放器必须先准备好。因此页面加载时间、暂停、后台时间不计入，特殊播放器不能保证触发。
- 默认素材放在 `extension/videos/`，路径由 `extension/video-config.js` 指定。
- 彩蛋画面里没有右上角“返回原视频”按钮。
- 彩蛋播完保持结束画面，原视频继续暂停、静音，不自动恢复、不自动重复。仍可通过工具栏“恢复原视频”、Esc 或 Alt+Shift+R 主动退出；关闭扩展开关也可恢复。
- 播放失败/长时间卡住会安全恢复；页面切换、视频节点移除等会清理覆盖。完成后切到后台或滚出可见区域会移除覆盖，但不会自动续播原视频。

## 安装与升级

1. 解压 ZIP。
2. 打开 Chrome 的 `chrome://extensions` 或 Edge 的 `edge://extensions`，启用开发者模式。
3. 新安装：加载已解压的扩展程序，选 `extension` 文件夹。
4. 升级：把新版 `extension` 内文件覆盖到之前加载的同一目录，在扩展管理页点击重新加载，再刷新视频网页。旧版残留的 assets 文件夹无影响。
5. 本次升级会**一次性**将触发规则改为 1–15 秒、100%、冷却 0 秒，并关闭自动续播。原启用/停用状态、同一视频一次设置、已导入视频保留。升级后再自行调整的规则不会因重新加载重复重置。

改为加载另一目录可能生成新的扩展身份，原导入内容和设置不一定跟随。

## 默认视频文件夹：如何放 MP4

当前默认素材为 [`extension/videos/default.mp4`](../extension/videos/default.mp4)，约 12.52 MiB。`extension/video-config.js` 已配置为 `videos/default.mp4`，使用当前文件不需要修改路径。

**默认视频出处：[B站 BV1iL8b6SEjU](https://www.bilibili.com/video/BV1iL8b6SEjU/)。**

如需更换为你有权使用的 MP4：

1. 复制到 `extension/videos/default.mp4`。
2. 如文件名不变，无需修改配置；如使用其他文件名，打开 `extension/video-config.js`，将 `DEFAULT_VIDEO` 改为相对于 `extension/` 的真实路径。
3. 在扩展管理页点击重新加载，刷新视频网页。
4. 若以前通过设置页导入过视频，导入内容优先。点击设置页 **“使用文件夹默认视频”**，才切换到文件夹素材（会删除扩展内的导入副本，不影响原文件）。

不要把 MP4 的扩展名直接改成 .webm。实际编码必须受浏览器支持。也可继续从设置页直接导入 MP4，不改文件夹或配置。

本版保留 1.1 的大视频支持：没有 50 MB、3 分钟或 185 秒硬限制。导入以 File/Blob 存在扩展 IndexedDB，使用 metadata 预读和 Blob URL，不将整片转成 base64 或 ArrayBuffer；实际内存、磁盘、配额及播放支持由浏览器决定。取消未提交导入、导入失败时保留旧文件。连续 45 秒没有实际播放进度才故障恢复，完成后该 watchdog 会关闭。

## 权限与边界

仅在自己或明确同意的人的浏览器使用。扩展访问 HTTP/HTTPS 页面来识别视频、暂停原片和覆盖视频区域；不上传视频、不收集浏览历史/账号，不使用外部网络服务。可在扩展管理页限制可访问网站。卸载会清除扩展内导入视频。

通用 HTML5 视频方案，Bilibili 和 YouTube 是目标场景，**并未完成真实站点兼容性验收**。小视频、广告容器（尽力识别）、原生 video 全屏、画中画、封闭 Shadow DOM、浏览器内部页及部分 DRM 播放器会跳过或失败。自动播放限制可能阻止切入；不保证零延迟。

## 测试

- `npm test`：126 项逻辑/模拟测试通过，包含长视频、完成后保持停止、无返回按钮和一次性设置迁移。
- `npm run check`：JS 语法、manifest 引用和内置素材检查通过。
- `npm run test:browser`：提供一次性 Chromium profile 的浏览器集成测试。当前环境 Chromium 启动被系统 socket 权限阻止，尚未运行任何浏览器断言；不可把模拟测试当成实机测试。

扩展安装无需 Node。开发测试需要 Node 20+，浏览器套件还需要 Playwright 与 Chromium。详见 [TESTING.md](../TESTING.md)。

# ThunderCut

看着看着，突然进入新宿决战。

一个免费开源的 Chrome / Edge 浏览器整活扩展，让网页视频随机切入本地短片，支持自定义 MP4 和触发时间。

**[下载 ZIP](https://github.com/daizzzR/thundercut/archive/refs/heads/main.zip)**

## 安装

1. 下载 ZIP 并解压。
2. 打开 `chrome://extensions`（Chrome）或 `edge://extensions`（Edge）。
3. 开启「开发者模式」，点击「加载已解压的扩展程序」。
4. 选择解压目录中的 **`extension` 文件夹**，刷新视频网页。

## 使用

点击扩展图标，开启随机彩蛋，或点「立即试一次」。默认在视频累计播放 **1–15 秒**后随机切入。

在「更换短片 · 调整触发规则」中导入自己的视频、调整触发时间和概率。

彩蛋播完会停在结尾。按 **Esc / Alt+Shift+R** 或点「恢复原视频」返回原片。

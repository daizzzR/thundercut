THUNDERCUT / LOCAL FIRST

给视频一点意外。

在观看途中，随机把视频区域换成你的短片。页面和原视频进度保留，彩蛋播完停在结尾，不自动继续原视频。

Chrome / Edge · Manifest V3本机存储无需账号

01 / 选择彩蛋短片

默认视频位于 extension/videos/default.mp4，也可在此导入自己有权使用的视频（导入内容优先）。其他文件名需修改 video-config.js。当前默认素材来自 Bilibili 视频 BV1iL8b6SEjU，第三方素材不适用工具代码的 MIT 许可；来源链接、版权及使用边界见项目 README。

不设固定文件大小或时长上限；实际受浏览器配额、磁盘和格式支持限制。建议 WebM 或 H.264 MP4。

02 / 设置随机规则

彩蛋结束后停在结尾，不自动续播原视频。

03 / 用之前知道这些

只对你自己或明确同意的人使用。避免在演示、考试、驾驶或其他需要专注的场景开启。所选视频可能包含突然出现的画面或声音。

本扩展会请求读取和修改 HTTP / HTTPS 网页的权限，以识别视频并放置播放器。不会收集浏览历史、账号、密码；没有统计、外部请求或上传。浏览器扩展管理页可限制可访问的网站。

导入文件仅保存在这个浏览器配置文件的扩展存储中，卸载扩展会清除。不要导入敏感或保密视频；已授权网页会显示你选择的画面。隐身模式默认不可用。

支持常见 HTML5 视频、网站播放器容器全屏和常见 SPA 页面。原生单独 video 全屏、画中画、封闭 Shadow DOM、浏览器内部页、严格禁止嵌入的站点及部分 DRM 播放器会跳过或失败恢复。广告识别是尽力而为，不能保证识别每个网站广告。

手动退出：Esc / Alt + Shift + R / 工具栏“恢复原视频”。画面内不显示返回按钮。
自动播放被浏览器阻止时会立即恢复；原片续播仍可能需要你点一次播放。
